# Recherche IA Google : application au site DOMTEKNIKA

Vérification et publication du 13 novembre 2026. Le commit applicatif `2d02452` a été construit sur Infomaniak et vérifié sur le domaine public.

## Référence officielle

Google a annoncé son [guide d’optimisation pour les fonctions de recherche générative](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide) le [15 mai 2026](https://developers.google.com/search/blog/2026/05/a-new-resource-for-optimizing). Ce n’est donc pas une annonce datée du présent audit.

Le guide privilégie les contenus utiles issus d’une expérience réelle, une structure technique accessible et les bonnes pratiques SEO. Il ne recommande aucun balisage spécial IA et indique que Google Search ignore `llms.txt`. L’indexation et la présence dans une réponse générée ne sont pas garanties. Le suivi se fait dans Search Console, notamment dans son rapport consacré aux fonctions d’IA générative lorsqu’il est disponible.

## Constats et corrections

| Point | Site public contrôlé | Correction dans le code |
| --- | --- | --- |
| Visibilité initiale du contenu | Le HTML comporte des blocs `data-reveal` avec `opacity:0` : cinq sur l’accueil français, quatre sur Expertise et seize sur Conception mécanique. Ils dépendent de JavaScript pour devenir visibles. | `Reveal` produit un contenu visible côté serveur. Après hydratation, seules les animations des blocs encore hors écran sont préparées. Les éléments déjà à l’écran restent visibles. |
| FAQ sans JavaScript | Les 51 questions sont déjà dans le HTML, mais les pages après les sept premières sont invisibles et `inert`. Elles demandent une interaction JavaScript pour devenir consultables. | Les 51 questions sont proposées comme accordéons HTML natifs dans le rendu initial. La recherche, les thèmes et la pagination s’activent après hydratation. Les visiteurs avec JavaScript conservent sept questions par page. |

Ces changements améliorent l’accès au contenu pour les visiteurs et les outils qui n’exécutent pas JavaScript. Ils ne prouvent pas une augmentation de classement ou de citations IA. Les réponses restent identiques pour les robots et les visiteurs ; aucun contenu spécifique à un agent utilisateur n’est ajouté.

## Fondations déjà présentes

- Le `robots.txt` public permet l’exploration des pages et protège `/api/`.
- Le sitemap public répond en HTTP 200 et contient 630 URL.
- Les trois pages françaises publiques contrôlées répondent en HTTP 200, autorisent l’indexation des pages et les extraits, et déclarent leur URL canonique.
- Les pages de prestations présentent déjà besoins, méthode, livrables, critères techniques, FAQ et liens vers des réalisations. Le site dispose de pages dédiées aux projets et brevets.
- Le code fournit des variantes linguistiques, des liens HTML et des données structurées d’organisation et de prestations. Ces signaux complètent le contenu ; ils ne constituent pas une garantie de sélection par Google.

La protection existante des images (`noimageindex` et en-têtes des médias) est conservée. L’audit du 22 octobre documente ce choix du site. Il limite les possibilités de visibilité des images ; le remettre en cause demanderait une décision distincte.

## Validation

- `npm run build` : TypeScript, audit des contenus et génération de production réussis.
- `npm test` : 32 tests réussis ; transports email simulés.
- ESLint sur les deux composants modifiés et `git diff --check` : réussis.
- HTML de production de 56 pages dans les sept langues : aucun bloc `Reveal` transparent initialement, canoniques attendues et JSON-LD syntaxiquement valide. Les 51 questions de chaque FAQ principale sont présentes et leurs groupes ne sont pas `inert`.
- Chromium avec JavaScript : pagination, recherche « PCB », absence de résultats et réinitialisation vérifiées.
- Chromium sans JavaScript : 51 questions accessibles et ouverture native d’une réponse vérifiée.
- Vue mobile de 390 × 844 : pagination et ouverture d’une réponse vérifiées, largeur du document de 390 pixels.

Les captures et relevés publics/locaux sont conservés dans le dossier d’audit `audit-seo-ia-2026-11-13`, à côté du dépôt. Ces contrôles locaux ne sont pas un nouveau score PageSpeed ni une mesure d’indexation.
